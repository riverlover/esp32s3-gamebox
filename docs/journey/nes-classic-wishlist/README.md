### 勇者斗恶龙3 的头修复

这份文件的 iNES1 头 mapper 字段损坏：两个映射字节解出来是 mapper 3843（不存在）。
但载荷是真的——512 KB PRG，数据区里能找到内嵌的 `DRAGON QUEST III` 字符串；
offset 0x10 的 32 位存储值**不是**真实 CRC32，所以它也排除了 iNES 2.0
（iNES 2.0 允许 mapper 字节省略，但 0x10 必须是 CRC32，这份不是）。
站内镜像里找不到可直接换的同名正作，于是按已知事实修头：DQ3 用 MMC5
（mapper 5，芯片带 micro），把 mapper 字段重写成「B6 低四位 = 5、B7 高四位清零」。
本仓库的 nofrendo（fceumm 内核）支持 MMC5，其余 mapper 0/1/3 更不用提。

**风险**：如果上板后这一款黑屏或花屏，说明这份修复还不够（flag 位或其他
元数据也可能被改坏，个别 DQ3 镜像还需要 softpatch），换一份来源即可，
不影响其他 19 款。

## 挑选规则（站内）

1. 用搜索，不要按首页 ID 往下翻。（**实际执行时没用搜索**：站点 robots.txt
   `Disallow: /*?q=*` 禁止搜索页，只允许目录页；改为把 `/?page=1..33`
   全部分页爬完建了 1543 个文件名的本地目录，再按关键词在本地匹配——
   范围比搜索大，顺带能发现同名重复文件。）
2. 同一作品多条时：选标题最短、无「中文金手指/无敌」字样的。  
3. 汉化版可以要（方便玩 RPG），但仍避免外挂改版。  
4. 拷进 TF 卡 `/roms/nes/` 后 RESET；不必重烧固件。

## 空间粗算

TF 卡容量远大于旧 13 MiB flash 分区；23 款 NES 原始合计大约几 MiB 量级，卡上随便放。

## 思考过程

- 该站「排名靠前」= ID 靠前，混了大量改版，不能当推荐榜用。  
- 清单按「装机必玩」而不是「全收集」：第一轮 20 个够玩，也够验证菜单翻页和 mapper 兼容。  
- 文件名加 `01xx` 前缀，是为了菜单按名排序时经典作聚在一起；平台仍由 ROM 头判定，目录名 `nes/` 只给人看。  

### 拉取执行记录（2026-08-30）

- 所有下载链接都指向同一个公开 S3 桶（`youxi.s3.bitiful.net`），直接 GET 对象即可，
  不需要登录；中文文件名要 URL 百分号编码（用 Python `urllib.parse.quote` 处理）。
- S3 桶的 LIST 接口超时不可用，没能列桶核对，只能靠站点页面建目录。
- 站内的数字前缀**不可靠**：不少文件叫 `0000xxx.nes`，有的干脆没有前缀
  （如 `赛尔达传说.nes`、`马戏团.nes`），所以按关键词+备注匹配，不迷信 ID。
- 同名重复文件用 MD5 判同：赤影战士的两个（0010/0018）完全相同；
  马戏团的两个（0215/无前缀）相同；雪人兄弟的两个（0083/0084）**不同**，
  是两个不同的改版，这也是它没有干净正作的佐证。
- 每个文件落库前都查了 iNES 头（magic、PRG/CHR 容量、mapper、0xFF 填充尾），
  全部有效，除了 DQ3 的 mapper 字段（见上节「头修复」）。
